# 題庫 JSON 規格（所有出題者必須遵守）

每個檔案是一個 JSON 陣列 `[ {...}, {...} ]`，UTF-8，不要加註解、不要用 ```json 包起來。

## 單題物件欄位

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | string | 全域唯一，格式見各任務指定的前綴，例如 `JV1-0001` |
| `level` | string | `J1` `J2` `J3`（國一～國三）/ `H1` `H2` `H3`（高一～高三）/ `IB`（銜接雅思） |
| `cefr` | string | `A1` `A2` `B1` `B2` `B2+` |
| `skill` | string | `vocab` `grammar` `cloze` `reading` `listening` `phrase` |
| `tag` | string | 弱點標籤，英文小寫加連字號，格式 `類別:細項`，例如 `grammar:present-perfect`、`vocab:daily-life`、`reading:inference` |
| `tag_zh` | string | 該標籤的繁體中文名稱，例如 `現在完成式` |
| `passage` | string \| null | 閱讀短文或聽力稿；非閱讀/聽力題填 `null` |
| `group_id` | string \| null | 同一篇文章的題目共用同一個 `group_id`，其他題填 `null` |
| `stem` | string | 題幹。填空題空格一律寫 `____`（四個底線） |
| `options` | string[] | 一定 4 個選項，不要寫 A. B. C. D. 前綴 |
| `answer` | int | 正確選項索引，0～3 |
| `explain_zh` | string | 繁體中文解析，2～4 句：為什麼對、其他選項為什麼錯、記憶重點 |
| `vocab` | array | 本題關鍵字，`[{"w":"generous","zh":"慷慨的","pos":"adj."}]`，1～4 個 |

## 硬性品質要求

1. **答案唯一正確**。其他三個選項必須在文法或語意上明確錯誤，不能有「也說得通」的。
2. **誘答有意義**。錯誤選項要對應學生常犯的錯（時態混淆、詞性錯、相似字混淆），不要用亂碼或明顯搞笑選項。
3. **題幹長度**：國中 8～18 字，高中 12～28 字，銜接雅思可到 35 字。
4. **不要重複**。同一檔案內 `stem` 不得重複，關鍵字也盡量不要重複超過 2 次。
5. **正確答案分布平均**：`answer` 為 0/1/2/3 的數量要接近各 25%，不要都集中在某一個。
6. **繁體中文**解析，台灣用語（例如「公車」不要寫「公交車」）。
7. 閱讀題：每篇 `passage` 120～220 字，後面配 4～6 題，`group_id` 相同。
8. 聽力題：`passage` 放**可以直接唸出來的英文稿**（80～150 字，對話請用 `A:` `B:` 開頭分行），學生作答前看不到稿子，所以題目不能依賴看稿。
9. 內容安全、適合學生，題材貼近台灣學生生活與雅思常見主題（教育、環境、科技、健康、旅遊、工作）。

## 寫檔前自我檢查

寫完後用這個指令驗證，必須印出 OK：

```bash
~/Desktop/IELTS-Camp/venv/bin/python ~/Desktop/IELTS-Camp/tools/check_bank.py <你的檔案路徑>
```

若驗證失敗，修正後再跑一次，直到 OK 才算完成。
